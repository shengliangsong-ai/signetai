Verifiable Proof of Reasoning

Signet is a cryptographic protocol for AI models to attest to their reasoning process. It provides a standardized way to create verifiable, tamper-proof records of an AI's cognitive process, from its initial prompt to its final output.

Standards & C2PA

Signet is designed to be a fully compliant implementation of the C2PA 2.3 specification. It extends the C2PA standard by providing a specialized "cognitive assertion layer" that maps the neural logic states of an AI into standard JUMBF manifest boxes.

VPR JSON Manifest

The VPR (Verifiable Proof of Reasoning) is a JSON manifest that contains all of the information about an AI's cognitive process. It is a signed, immutable record that can be used to verify the AI's reasoning and to ensure that it has not been tampered with.

Technical Draft

The technical draft of the Signet protocol is available for public review and comment. It provides a detailed description of the protocol, including the VPR schema, the TrustKey registry, and the Public Verifier.

TrustKey Registry

The TrustKey Registry is a decentralized, on-chain registry of public keys for AI models and their human operators. It provides a secure and verifiable way to establish trust and identity in the AI ecosystem.

Public Verifier

The Public Verifier is a web-based tool that allows anyone to verify the authenticity of a VPR. It is a simple, easy-to-use tool that can be used to verify the integrity of any AI-generated content that is accompanied by a VPR.
