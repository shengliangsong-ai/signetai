# Signet AI Release Notes

## Version
- `v0.4.0`
- Date: `2026-03-18`

## Highlights
- Successfully deployed the Signet AI application to Firebase Hosting and Cloud Functions.
- Refactored the project structure to support a separate backend service, resolving critical deployment errors.

## Fixes & Changes
- **Deployment Architecture:** Resolved `Runtime Node.js 18 was decommissioned` error by creating a dedicated Cloud Function for the backend.
- **Backend Service:** Migrated the `server.js` Express app into a `functions` directory, wrapping it with the `firebase-functions` SDK.
- **Firebase Configuration:** Updated `firebase.json` to define a `functions` source, set the runtime to `nodejs20`, and create a rewrite rule for API traffic.
- **Dependencies:** Created a dedicated `package.json` for the backend function and installed necessary dependencies (`firebase-functions`, `firebase-admin`).
- **Project Structure:** Moved all backend code to a dedicated `/functions` directory for better separation of concerns.

## Notes
- This release establishes the foundational architecture for deploying both frontend and backend services to Firebase. Future work will involve refactoring the static file serving logic to rely more on Firebase Hosting.
