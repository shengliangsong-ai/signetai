# Signet AI Release Notes

## Version
- `v0.4.1`
- Date: `2026-03-19`

## Highlights
- Fixed Live Assistant text chat functionality by implementing a server-side proxy.

## Fixes
- Resolved 'Logic drift detected' error caused by client-side API calls returning HTML instead of JSON.
- Added `axios` dependency for server-to-server API requests.
- Created a `/api/chat` endpoint in Vite to proxy requests to the Gemini API.
- Updated GitHub Actions build process by committing `package-lock.json` to include the new `axios` dependency.

## Breaking Changes
- None

## Notes
- This change improves the reliability of the Live Assistant and aligns its text-based chat with best practices for handling API keys and requests.
